内网文件共享 Windows 版（0.1.0）
================================

一、主电脑怎么使用

1. 将 LanFileHub-Windows-x64.exe 放到主电脑上的固定位置。
2. 双击运行程序。
3. 如果 Windows 防火墙询问是否允许访问，请只勾选“专用网络”。
4. 浏览器会自动打开首次设置页面。
5. 点击“选择文件夹”，指定主电脑上的一个本地目录作为共享文件夹。
6. 设置管理员账号和密码，然后点击“完成设置并开始共享”。

二、其他电脑怎么访问

1. 主电脑页面顶部会显示类似下面的地址：
   http://192.168.1.20:3923
2. 让其他 Windows 或 Mac 电脑连接到同一个局域网。
3. 在浏览器中输入主电脑显示的地址。
4. 使用主电脑设置的账号和密码登录。

三、支持的操作

- 浏览文件夹
- 上传多个文件
- 下载文件
- 覆盖更新同名文件
- 新建文件夹
- 重命名文件或文件夹
- 删除文件或文件夹

四、更换共享目录或停止服务

只能在主电脑上操作：

1. 打开程序页面。
2. 点击右上角“设置”。
3. 可以重新选择共享文件夹，或者点击“停止共享服务”。

五、重新启动

服务停止后，再次双击 LanFileHub-Windows-x64.exe 即可重新启动。
如果程序已经运行，再次双击只会重新打开管理页面，不会启动第二个实例。

六、重要提醒

- 本工具用于可信任的家庭或办公内网，不要将 3923 端口开放到互联网。
- 删除操作暂时不会进入回收站，请确认后再删除。
- 单个上传文件最大 20GB。
- 配置和运行日志保存在 %APPDATA%\LanFileHub。
- 当前程序没有商业代码签名，Windows 第一次运行时可能显示“未知发布者”。
